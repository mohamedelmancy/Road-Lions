## 🚀 Deploy Now (2 Simple Steps)

### Step 1: Push to GitHub

```bash
git push origin main
```

If this is your first time, you might need to authenticate with GitHub:
- **Username:** mohamedelmancy
- **Password:** Use a Personal Access Token (not your GitHub password)
  - Generate one here: https://github.com/settings/tokens
  - Click "Generate new token (classic)"
  - Select `repo` permissions
  - Copy the token and use it as your password

---

### Step 2: Deploy to GitHub Pages

Once pushed to GitHub, deploy with a single command:

```bash
npm run deploy
```

This will:
- ✅ Build your production-ready website
- ✅ Create a `gh-pages` branch automatically
- ✅ Deploy to GitHub Pages
- ✅ Make your site live at: **https://mohamedelmancy.github.io/Road-Lions/**

---

## ⚙️ Configure GitHub Repository (One-Time Setup)

After deploying, configure GitHub Pages:

1. Go to: https://github.com/mohamedelmancy/Road-Lions/settings/pages
2. Under **Source**, select:
   - **Branch:** `gh-pages`
   - **Folder:** `/ (root)`
3. Click **Save**
4. Wait 1-2 minutes
