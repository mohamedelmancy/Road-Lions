LOGO SETUP INSTRUCTIONS
========================

Please add your Road Lions logo to this folder:

1. Save your logo image as: logo.jpeg
2. Place it in this directory: /public/logo.jpeg
3. The logo should be a PNG file with transparent background for best results
4. Recommended size: 300x300 pixels or larger (will auto-resize)

The logo is already referenced in:
- Header component
- Footer component  
- About page
- HTML head (as favicon)

Once you add logo.jpeg to the /public folder, it will automatically appear throughout the website.

You can use the logo image you provided earlier (the Road Lions car with lion design).
