## 📤 Push to GitHub (Choose One Method):

### Method 1: Using Terminal (Recommended)

Open Terminal and run:

```bash
cd "/Users/mohamedelmancy/Road Lions/website"
git push -u origin main
```

**You'll be prompted to:**
1. Enter your GitHub username
2. Enter your Personal Access Token (not password!)

---

### Method 2: Using GitHub Desktop (Easiest)

1. **Download GitHub Desktop**: https://desktop.github.com/
2. **Open the app**
3. **File** → **Add Local Repository**
4. **Select**: `/Users/mohamedelmancy/Road Lions/website`
5. **Publish Repository** button
6. Done! ✅

---

## 🔑 Need a Personal Access Token?

If you don't have a token:

1. **Go to**: https://github.com/settings/tokens
2. **Click**: "Generate new token (classic)"
3. **Name**: "Road Lions Website"
4. **Permissions**: Select `repo` (full control)
5. **Generate** and copy the token
6. **Use this token** instead of password when pushing

## 🆘 Troubleshooting:

### "Authentication failed"
- Use **Personal Access Token**, not password
- Generate token at: https://github.com/settings/tokens

### "Repository not found"
- Make sure repository exists: https://github.com/mohamedelmancy/Road-Lions
- Check spelling and capitalization

### "Permission denied"
- Use GitHub Desktop instead
- Or use HTTPS with token
